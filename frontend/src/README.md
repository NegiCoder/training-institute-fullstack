# Source Folder Guide

This folder uses an industry-style React structure.

- `app/` - app-level providers and setup.
- `components/` - reusable UI components shared across features.
- `config/` - environment and app configuration.
- `features/` - feature modules like auth, admin, student, trainer, courses.
- `hooks/` - reusable custom React hooks.
- `layouts/` - page layouts like dashboard layout and auth layout.
- `pages/` - route-level pages.
- `routes/` - React Router route definitions and route guards.
- `services/` - API service functions that call the ASP.NET backend.
- `store/` - global state such as auth store.
- `types/` - TypeScript interfaces matching backend DTOs.
- `utils/` - small helper functions.
